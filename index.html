Правила работы

Главная / Правила

📋 Основные положения

  • Безопасность: Все данные передаются по защищённому каналу. Не передавайте свои логины/пароли третьим лицам.
  • Ответственность: Вы несёте полную ответственность за свои транзакции и операции.
  • Запрещено: Использование площадки для мошеннических схем, отмывания средств или других незаконных действий.
  • Комиссии: Размер комиссий указан в разделе «Финансы» и может меняться уведомлением за 3 дня.

🚫 Нарушения

При обнаружении нарушений ваша учётная запись может быть заблокирована без предупреждения. Все спорные ситуации решаются через раздел «Споры».

Функционал и работа

Главная / Функционал

⚙️ Что вы можете делать на площадке

  • Профиль: управление личными данными, смена пароля, настройки уведомлений.
  • Дашборд: главная страница с виджетами: баланс, последние транзакции, статус PayIn/PayOut.

Профиль

Главная / Профиль

📌 1. Rate

  • Указан статус аккаунта (заблокирован = неактивен, разблокирован = активен).
  • Указаны общие ставки на токене трейдера для PayIn/PayOut.

💰 2. Баланс

  • Рабочий баланс — используется для работы.
  • Замороженный баланс — «морозится» при активных / спорных ордерах на их сумму в $.
Если заявка становится успешной — деньги из «Заморожено» списываются.
Если заявка становится отменённой — деньги из «Заморожено» возвращаются на «Рабочий» баланс.
  • Страховой депозит — выставлен Администратором (не показывает реальный страховой депозит трейдера).

📈 3. Доход

  • PayIn: текущий доход (вознаграждение) от заявок на вход.
  • PayOut: текущий доход (вознаграждение) от заявок на выход.

  • Уровни комиссий: ставка PayIn/PayOut для разных диапазонов чеков у данного мерчанта.

Дашборд

Главная / Дашборд

📊 Основные показатели дашборда

  • 1. Общая комиссия: общий доход со всех сделок в рублях.
  • 2. Выполненные заявки: за всё время на Покупку/Продажу.
  • 3. Активные заявки: в данный момент (в ожидании / в обработке).
  • 4. Общий оборот: сумма всех выполненных заявок за всё время в рублях.
  • 5. Интерактивная диаграмма: полученный доход по дням (график).
  • 6. Фильтр дат: выбор периода для отображения данных.
  • 7. Конверсия по реквизитам: процент успешных заявок по каждому реквизиту за период.
  • 8. Объём по реквизитам: принятая сумма на каждый реквизит за период.
Конверсия реквизитов и объём по реквизитам

Средняя конверсия: отображается общий процент успешных заявок по всем реквизитам.

Объём по реквизитам: показывает сумму принятых средств по каждому реквизиту за выбранный период.

В истории транзакций отображены все финансовые изменения всех балансов по каждой заявке. У каждой заявки есть свой ID, тип, сумма, статус, Баланс до, Баланс после, дата, кнопка для подробного просмотра информации по заявке

  • Вывод (ордер): списания с "Рабочего" баланса за успешную заявку
  • Кнопка для подробного просмотра информации по заявке

При нажатии на кнопку "Пополнить баланс" открывается окно заполнения, в котором указан адрес пополнения, на который необходимо совершить перевод.

Окно пополнения баланса

После отправки средств необходимо указать точную сумму отправки (без комиссии), указать хэш транзакции и нажать кнопку «Создать заявку».

После создания справа от заявки будет кнопка «Проверить» (10 пункт), она необходима для автоматической сверки хэша транзакции и суммы заявки. При верном указании хэша и суммы — заявка переходит в статус «Успешно» и баланс пополняется.

При неправильном вводе суммы или хэша необходимо создать новую заявку с верными данными. 1 хэш = 1 пополнение

Окно вывода доходного баланса

Для вывода необходимо вписать сумму вывода с учётом комиссии, а также адрес для вывода. После создания заявки начнётся таймер. На заявку отводится 24 часа.

10. Кнопка справа заявки (ПРОВЕРИТЬ) — для автоматической проверки пополнения.

PayIn

Главная / PayIn
Заявки на продажу (PayIn)

Визуал вкладки PayIn во многом схож с PayOut. Из нового могу выделить указание реквизитов пополнения, а также кнопка «Документ» для получения документа об оплате от мерчанта.

Также под курсом красной стрелочкой обозначена сумма в $, которая будет списана с «Рабочего» баланса при успехе, зелёной стрелочкой обозначена сумма, которая будет начислена в качестве вознаграждения на доходный «PayIn» баланс.

При подтверждении активной/спорной/истекшей заявок потребуется повторное нажатие кнопки «Подтвердить» во избежание случайного подтверждения заявки.

Подтверждение заявки

При подтверждении заявки система запросит повторное подтверждение во избежание случайного нажатия.

Разбор работы с активной заявкой PayOut

Разбор работы с активной заявкой PayOut

Подтверждение выплаты

У каждой активной заявки есть таймер, который устанавливает мерчант. У трейдера есть возможность отменить или подтвердить выплату.

При подтверждении выплаты необходимо прикрепить доказательство совершения выплаты. Для выплаты по СБП обязательно необходим документ в формате ПДФ для проверки в чекере на подлинность.

Для выплаты по С2С методу можно прикреплять любые доказательства до 100 Мб.

Ожидание админа

После прикрепления доказательств оплаты при отключенной функции «Автоапрув» (настраивает Администратор) заявка падает в статус «Ожидание админа». Данная заявка должна быть проверена Администратором и после подтверждения заявка считается успешной.

Отмена заявки

Отмена заявки

Причина отмены

Для отмены выплаты необходимо указать причину отмены. При отмене по причине «Карта заблокирована» необходимо прикрепить доказательство и заявка отменяется с отправкой callback мерчанту об отмене.

При выборе остальных причин ничего прикреплять не нужно. Такая заявка распределяется на другого трейдера, либо в общий пул (хранилище выплат для последующего распределения трейдерам).
